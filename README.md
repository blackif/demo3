# 绝境猜约（Last Hand）原型

受有限猜拳、生存资源与心理博弈启发的原创浏览器游戏。当前版本为双人同设备轮流出牌的可玩规则验证版。

## 运行与部署

游戏现在作为主站首页部署，预期地址为 https://blackif.github.io/demo3/。源码保留在 public/last-hand/ 作为原始副本。

## 规则

- 双人对战，每人 12 张牌：石头、剪刀、布各 4 张。
- 每人初始 3 颗星星。
- 双方每轮各选一张未使用卡牌；提交后不可撤回。
- 胜者从败者处获得 1 颗星星，平局不转移星星。
- 星星归零即淘汰；最多进行 12 轮，最终星星较多者获胜。
- 本地同屏模式不是安全联机，交接设备时应避免看到对手选择。

## 真人联机架构

GitHub Pages 只能托管静态前端，不能作为 WebSocket 房间服务器。建议前端仍部署于 GitHub Pages，后续采用 Cloudflare Workers + Durable Objects + WebSocket 管理房间状态；或使用 Supabase Realtime。

服务端必须是权威状态源：验证玩家席位、卡牌剩余数、提交阶段、回合截止时间与重复请求；仅当双方都提交后才揭示卡牌；星星转移由服务端计算，客户端不得自行提交胜负或资源数量。房间支持短码加入、断线重连、超时规则和对局日志。
